## 下载说明

- `WalkGate-v0.3.4-macOS-Universal.dmg`：主要安装包，同时支持 Apple Silicon 与 Intel Mac。
- `WalkGate-v0.3.4-macOS-Universal.zip`：备用便携包，同时支持 Apple Silicon 与 Intel Mac。

安装包采用项目自签名证书，尚未经过 Apple Developer ID 公证。首次打开时，请按照 README 中的“隐私与安全性”步骤允许 WalkGate 运行。
