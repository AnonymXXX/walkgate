## 主要更新

- 休息卡片弹出后立即开始倒计时，不再等待键盘和鼠标静置 5 秒。
- 达到最低休息时长后继续显示 `+00:01、+00:02…` 的额外休息时间。
- 只有手动点击“进入工作模式”才结束休息并开始下一轮工作计时。
- 提高休息卡片的磨砂强度和背景对比度，避免底部代码、网页文字干扰阅读。
- 同步设置页与 README 中的休息计时说明。

## 下载说明

- `WalkGate-v0.3.2-macOS-Universal.dmg`：主要安装包，同时支持 Apple Silicon 与 Intel Mac。
- `WalkGate-v0.3.2-macOS-Universal.zip`：备用便携包，同时支持 Apple Silicon 与 Intel Mac。

安装包采用 ad-hoc 签名，尚未经过 Apple Developer ID 公证。首次打开时，请按照 README 中的“隐私与安全性”步骤允许 WalkGate 运行。
