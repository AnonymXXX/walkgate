## 主要更新

- 修复 Mac 睡眠后重新唤醒时，WalkGate 菜单栏界面可能持续显示加载状态的问题。
- 睡眠期间暂停状态刷新定时器，并在唤醒后恢复，避免无效刷新干扰系统唤醒。
- 仅在菜单或休息卡片可见时发布秒级状态变化，降低后台刷新和 CPU 占用。
- 补充睡眠、唤醒及状态刷新策略的自动化测试。

## 下载说明

- `WalkGate-v0.3.3-macOS-Universal.dmg`：主要安装包，同时支持 Apple Silicon 与 Intel Mac。
- `WalkGate-v0.3.3-macOS-Universal.zip`：备用便携包，同时支持 Apple Silicon 与 Intel Mac。

安装包采用项目自签名证书，尚未经过 Apple Developer ID 公证。首次打开时，请按照 README 中的“隐私与安全性”步骤允许 WalkGate 运行。
