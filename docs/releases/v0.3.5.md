## 主要更新

- 重构状态栏与主面板生命周期，修复打开设置并切换桌面后状态栏可能显示空白的问题。
- 状态栏只保留行走图标，主面板恢复 macOS 原生磨砂材质，并与状态栏图标左边缘对齐。
- 改进设置窗口的激活、关闭与焦点处理，并同步显示系统通知权限状态。

## 下载说明

- `WalkGate-v0.3.5-macOS-Universal.dmg`：主要安装包，同时支持 Apple Silicon 与 Intel Mac。
- `WalkGate-v0.3.5-macOS-Universal.zip`：备用便携包，同时支持 Apple Silicon 与 Intel Mac。

安装包采用项目自签名证书，尚未经过 Apple Developer ID 公证。首次打开时，请按照 README 中的“隐私与安全性”步骤允许 WalkGate 运行。
