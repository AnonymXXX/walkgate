## 主要更新

- 主面板改用与 MemoryGuard 一致的 macOS 原生 `.menu` 磨砂材质。
- 清除 SwiftUI 与 AppKit 窗口承载层的实色背景，让桌面颜色自然透入。
- 提高主面板与休息卡片的通透度，同时保持文字、图标和按钮清晰。
- 减弱面板边框与分隔线，整体更接近系统菜单的轻盈质感。

## 下载说明

- `WalkGate-v0.3.1-macOS-Universal.dmg`：主要安装包，同时支持 Apple Silicon 与 Intel Mac。
- `WalkGate-v0.3.1-macOS-Universal.zip`：备用便携包，同时支持 Apple Silicon 与 Intel Mac。

安装包采用 ad-hoc 签名，尚未经过 Apple Developer ID 公证。首次打开时，请按照 README 中的“隐私与安全性”步骤允许 WalkGate 运行。
