## 主要更新

- 新增可配置工作日程：支持设置上下班时间，以及午休、下午休息等多个休息时段。
- 进入休息时段或下班后暂停提醒；重新进入工作时段时，从完整工作周期重新计时。
- Mac 睡眠达到最低休息时长后，在首次操作时开始新的工作周期，避免刚唤醒就弹出休息提示。
- 设置窗口打开时不再默认选中时间输入框。
- 优化休息完成卡片布局，缩小高度并保持状态切换时的视觉稳定。
- 使用全新的“活力轨迹”应用图标，强化运动、健康与日常活动的视觉语言。

- `WalkGate-v0.3.0-macOS-Universal.dmg`：主要安装包，同时支持 Apple Silicon 与 Intel Mac。
- `WalkGate-v0.3.0-macOS-Universal.zip`：备用便携包，同时支持 Apple Silicon 与 Intel Mac。
